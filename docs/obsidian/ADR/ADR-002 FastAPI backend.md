# ADR-002 FastAPI backend

## Context

API tipada con validación y OpenAPI.

## Decision

FastAPI, Pydantic, servicios separados y httpx con timeouts.

## Alternatives

Django añade administración no requerida; Flask exige más integración manual.

## Consequences

Contratos testeables; sin reglas financieras en endpoints.
