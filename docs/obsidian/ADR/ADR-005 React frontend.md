# ADR-005 React frontend

## Context

Interfaz interactiva de gráficos y formularios.

## Decision

React, TypeScript, Vite, Tailwind y Lightweight Charts; proxy local al backend.

## Alternatives

SSR no aporta valor a una aplicación privada local; Sites/cloud no corresponde al requisito offline.

## Consequences

Sin claves en bundle; API tipada, tests de interacción, modo oscuro/claro.
